# C/C++ Programming Fundamentals

A collection of programming exercises from my introductory programming coursework.

This repository documents my early programming practice and the development of fundamental problem-solving skills through a series of C/C++ exercises.

## Repository Structure

```text
Programming-Fundamentals/
├── 01_Basic_Exercises/   # Exercise set 1
├── 02_Exercises/         # Exercise set 2
├── 03_Exercises/         # Exercise set 3
├── 04_Exercises/         # Exercise set 4
├── 05_Exercises/         # Exercise set 5
├── Exam/                 # Exam practice / solutions
├── .gitignore
└── README.md
```

## Contents

The exercises include introductory programming practice such as:

- Basic input and output
- Variables and arithmetic operations
- Conditional statements
- Loops and iterative problem solving
- Functions and basic program decomposition
- General programming exercises

## Language

The source files use the `.cpp` extension, while many exercises follow a C-style programming approach using headers and functions such as `stdio.h`, `printf`, and `scanf`.

## Notes

- Only source code is included in this repository.
- Compiled executable files are intentionally excluded.
- The original exercise numbering is preserved where possible to retain the learning sequence.

## Purpose

This repository serves as a record of my early programming coursework and programming fundamentals. More advanced projects and research-related implementations are maintained separately.
